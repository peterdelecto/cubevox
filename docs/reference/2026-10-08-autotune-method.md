# Autotune method (2026-10-08)

Technical handoff for the Autotune card as it stands after the pitch CPU pass
(e06d829). The design spec is `docs/specs/2026-10-01-autotune-design.md`; the
CPU pass and its grill decisions are `docs/specs/2026-10-08-pitch-cpu-pass-design.md`.

## Signal path

1. Input block (64 samples, 48 kHz) → shared 4800-sample ring `ring_` → `PitchTracker` (analysis) → `AutotuneVoice` (target + smoothing + PSOLA resynthesis) → equal-gain crossfade with the dry input. Files are `engine/pitch.h`, `engine/autotune.h`, `engine/psola.h`, `engine/pitch_fx.h`, `engine/fastmath.h`.
2. Default engine is 0, grid PSOLA. Engine 1 (epoch PSOLA, `engine/shifters.h`) is selectable and not covered here.
3. Latency is fixed at 1040 samples (21.7 ms) by `grainDelay`; the unvoiced pass-through reads the ring at the same delay so the crossfade is time-aligned.

## Tracker front end

1. Full-rate ring `full_` 2048 samples, decimated ring `dec_` 512 samples. Each write lands at `pos` and `pos + len`, so the newest span is contiguous and analysis reads in place, no copy.
2. Anti-alias before decimation is an RBJ 2-pole Butterworth low-pass, f_c = 2500 Hz, Q = 1/√2, then keep every 4th sample → 12 kHz.
3. Analysis runs every hop of 256 samples (5.33 ms, every 4th block) while a consumer is on, plus once on the enable edge. Rings fill always, so an enable reports pitch instantly.

## Coarse pass (YIN at 12 kHz)

1. Difference function over W = 256 decimated samples (21.3 ms), lags τ = 1..171 (70 Hz..1 kHz):
   d(τ) = Σ_{j=0}^{W−1} (x[j] − x[j+τ])²
2. Cumulative mean normalised difference:
   d′(τ) = d(τ) · τ / Σ_{k=1}^{τ} d(k), d′ = 1 where the sum is 0.
3. Pick rule with θ = `voicedThreshold` = 0.15. Take the first τ ≥ 12 with d′(τ) < θ, then walk right while d′ keeps falling. If none dips below θ, take argmin d′. Frame is periodic iff min d′ < θ.
4. Parabolic refinement of the pick, a = d′(τ−1), b = d′(τ), c = d′(τ+1):
   δ = ½ (a − c) / (a − 2b + c), clamped to ±1, 0 unless a − 2b + c > 0. τ_c = τ + δ.
5. Lags go in pairs (`sumSqDiff2`) so τ and τ+1 share loads; four accumulators keep the M7 FPU pipeline full. Cost ≈ 171 × 256 = 43.8k MACs.

## Fine pass (48 kHz)

1. Centre lag T = round(4 τ_c). Search T ± 4, clamped to [48, 686].
2. Plain difference over W = 1024 samples, d(τ) = Σ_{j=0}^{1023} (x[j] − x[j+τ])², 9 lags ≈ 9.2k MACs. The frame is the newest 1024 + 686 samples.
3. Same parabola on the three d values around the minimum gives the fractional period P in samples.
4. Voiced iff the coarse pass was periodic and RMS over the fine window > 0.00316 (−50 dBFS).

## Publish

1. Period published is the median of the last three voiced periods (kills single octave jumps). hz = 48000 / P_median.
2. rawHz = 48000 / P_newest, one hop fresher. Autotune targets from rawHz; the PSOLA period uses the median.
3. Unvoiced frames keep the last period (so grains keep running) and hold the last correction target.

## Correction target (per block)

1. MIDI pitch m = 69 + 12 log₂(f / 440).
2. Chromatic mode c = ⌈m − ½⌉ − m (ties snap down).
3. Scale mode with key root R and major set M = {0, 2, 4, 5, 7, 9, 11}:
   rel = (m − R) mod 12, s_d = rel − M_d wrapped into [−6, 6), d* = argmin |s_d|, ties within 1e-4 go to s > 0 (snap down). c = −s_{d*}.
4. Clamp |c| ≤ `maxCorrectSemis` = 6 (tracker glitch guard).
5. First voiced frame after reset or enable snaps corr = c directly (no glide from 0).

## Response smoothing (per sample)

1. One-pole, corr ← corr + a (c − corr), a = 1 − exp(−1 / (τ · 48000)), τ = RESPONSE in seconds, 1..500 ms. Snaps to target within `kSnap`.
2. Knob taper is log, τ(k) = 500 ms · (1/500)^k, k = 0 NATURAL .. 1 MECHANICAL. 1 ms is hard tune.
3. Pitch ratio r = 2^{corr/12} via `exp2Fast`. Degree-6 polynomial on the fraction in [−½, ½], integer part written into the float exponent field. Relative error 3.8e-7 over ±12. Clamped 0.5..2.0 in PSOLA.

## Resynthesis (grid PSOLA, Lent 1989)

1. Input marks are a grid spaced P apart, tracked as a delay behind the write head so the state stays bounded. The newest mark sits at or under grainDelay (1040).
2. Output period P_o = P / r. A countdown launches one grain every P_o output samples.
3. Each grain has length L = 2P, centre at the nearest grid mark to the delay line, and reads the ring at a constant delay (centre + P − lead). Up to 8 live grains; the oldest is stolen if all are busy.
4. Hann window w[n] = ½ (1 − cos(2πn / L)) is generated by a complex rotor, no cos per sample:
   (c, s) ← (c·dc − s·ds, s·dc + c·ds), dc = cos(2π/L), ds = sin(2π/L), w = ½(1 − c). Drift ≈ n · 1e-7 per grain; re-initialised at every launch.
5. Fractional read is Catmull-Rom at position head − delay, f = frac:
   c₁ = ½(x₁ − x₋₁), c₂ = x₋₁ − 2.5x₀ + 2x₁ − ½x₂, c₃ = ½(x₂ − x₋₁) + 1.5(x₀ − x₁), y = x₀ + f(c₁ + f(c₂ + f c₃)).
6. Output y = (1/r) Σ_g w_g · x_g. The 1/r keeps level flat as grain density scales with r. Formants stay put because grains are cut at the input period and only re-spaced.
7. Trim gain 10^{trimDb/20}, trimDb = 0 under the level rule.

## Crossfade and block rate

1. activeAt smooths 0→1 over 20 ms (`kSmoothCoef`) on enable; out = at · tuned + (1 − at) · in. Before the first voiced frame, tuned = in delayed by 1040 samples.
2. All smoothers step per sample but the sin/cos gains are evaluated only at block edges and lerped with f = (i+1)/n. Bit-exact once settled.
3. Idle path when every pitch stage is settled off copies in → out and only writes rings (0.9 % of a block).
4. Tracker runs only when Autotune, Harmony, or Octave A/B is on. Octave C (default) needs no pitch.

## Cost (share of a 640k-cycle block, WeAct H743, voice clip)

| Part | Cost |
|---|---|
| Tracker hop block (every 4th block) | ≈ 31 % |
| PSOLA voice, per block | ≈ 5.6 % |
| Shared per-sample loop | ≈ 3.6 % |
| Autotune average (slot with Autotune off → on) | ≈ 13.6 % |
| Pitch slot average / worst | 21.9 % / 45 % |

The tracker burst is ≈ 53k MACs at ≈ 3 cycles per MAC, instruction-issue bound. The remaining lever for the burst is an FFT-based difference function for the coarse pass or a sliding update with spread rebase.

## Gates

1. `ctest` hard tune ≤ 4 cents RMS (now 3.76). A step that tips it is redone, never loosened.
2. `pitch` test vibrato 5 Hz ±30 cent within 3 cents at every voiced hop (now 1.34), steady 220 Hz 0.04 cents, silence unvoiced, no allocation.
3. `tools/engine_ab.sh <ref> --tol <dB>` across 10 cases, −60 dB floor for inexact steps, −200 for bit-exact.
4. The pitch CPU pass spec holds the grill decisions. Analysis stays at the hop boundary; spreading it adds 5.3 ms and breaks the hard-tune gate.
